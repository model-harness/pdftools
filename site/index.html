A PDF is a drawing of a page.

pdfspec reads it back into Markdown, with the words, columns, headings and tables put together again, for people and for language models.

What the drawing leaves out

PDF was made in the era of print, to make a page look the same on every screen and every printer. It does that by describing the page as vector shapes: draw a “T” here in this font, an “h” just to its right, a line under the heading. That’s perfect on paper. Everything else has to be worked out again.

  • #

    The spaces

    The gap between two words is only a little extra distance between two shapes. Something has to notice it and decide it’s a space.

  • tr

    The reading order

    Two columns are just shapes on the left and shapes on the right. Nothing says to finish the left one first.

  • ¶

    Paragraphs and headings

    A heading is only bigger, bolder shapes. A paragraph ends where the shapes happen to stop.

  • Tables

    A table is letters lined up in rows, sometimes with ruled lines drawn around them and sometimes with nothing at all.

  • Page furniture

    Running headers, footers and page numbers are drawn right beside the content, with nothing marking them as different.

  • Letters with no name

    Some fonts draw “fi” or “ti” as one shape and never say which letters it stands for. A scanned page has no letters at all, only a photograph.

The marks in the margin are a proofreader’s: insert a space, transpose, start a new paragraph. They’re the corrections every PDF reader has to make without being told where.

Most tools stop at the letters

We ran pdfspec against two other common tools using the same 17-page research paper, and found the following.

pdfplumber 0.11.939,0892,392377 (15.8%)110

All three found the same characters, to within a fraction of a percent. The difference is the spaces. pdfplumber found just over a third as many words, and one in six of its “words” ran past 25 characters, because it missed the gaps between them. One of the Go libraries we tried found a space in only 0.01% of its text.

The other fashionable answer is to show every page to an AI vision model. It works, but it costs far more and takes far longer than reading text the file already contains, and a model that can’t make something out tends to guess.

How pdfspec reads a document

It treats the file as the best witness to its own content, and only looks further when the file runs out.

  1. The file itself

    Words from the gaps between letters, reading order from the columns, headings from size and weight, tables from their lines or their alignment. Running headers and page numbers are set aside.

  2. Text recognition

    Where the file holds only a picture, such as a scan, a screenshot of a table, or a letter with no name, Tesseract, which comes with pdfspec, reads it.

  3. A second opinion

    Where even that isn’t sure, a vision model you run yourself, through inferd, checks the doubtful word, or describes a chart or a photo.

What nothing could read, pdfspec doesn’t guess. It writes [err] for a letter and [image] for a picture, and tells you which pages they’re on.

Try it on your own files

Convert a file

curl -fsSL https://raw.githubusercontent.com/model-harness/pdftools/main/install.sh | sh
pdfspec md report.pdf > report.md

On Windows, run irm https://raw.githubusercontent.com/model-harness/pdftools/main/install.ps1 | iex in PowerShell. Either installer checks the download against the release’s checksums first, and adds pdfspec to your PATH for the next terminal you open. With Go, go install github.com/model-harness/pdftools/cmd/pdfspec@v1.1.1 works too.

That is the whole tool. It comes with its own copy of Tesseract, so scanned pages are read without anything else to install. To have pictures and charts described too, add PDFSPEC_WITH_INFERD=1 to the install, which sets up inferd, a vision model that runs on your own machine. Its model is a 6 GB download the first time it starts.

Look before you convert

pdfspec probe report.pdf

probe describes a file without converting it: how pdfspec will read it, which helpers it found, and which pages would need them.

It’s also a Go library, and it comes with a skill for coding agents such as Claude Code and Codex, so they use pdfspec whenever they need what’s inside a PDF.
